Offline evaluation harness. Splits: tuning / validation / calibration / test / adversarial with no query or PMID overlap. Metrics: retrieval (R@k, MRR, nDCG, first relevant rank), generation (claim entailment, unsupported/contradiction rate, citation and numeric/entity fidelity), trust (false PASS/WARN/BLOCK, abstention quality, ECE, Brier, coverage-risk), performance (p50/p95/p99, VRAM, RAM).
